Ready-to-run Linux

Install EZVM and Omarchy together.

One command installs or updates the signed EZVM app, verifies the latest Omarchy AArch64 installer against its published Release checksum, and imports the preinstalled sparse image.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/everettjf/ezvm/main/scripts/install-omarchy.sh)"

Requires Homebrew · Downloads about 2.84 GiB · Installs to ~/EZVM Virtual Machines/Omarchy.ezvm

A complete native workflow

Powerful where it matters. Quiet everywhere else.

01

Download at the end

Choose your system and hardware first. EZVM downloads only after you click Create, resumes interrupted downloads, and reuses saved images.

02

Snapshot branches

Create a history tree, restore an ancestor, branch in another direction, search snapshots, protect important points, and see their storage cost.

03

Safe lifecycle

Exclusive run leases protect writable disks while normal boot, Recovery, save-state, shutdown, and restart share one lifecycle.

04

Modern storage

ASIF disks by default, APFS copy-on-write snapshots on macOS 26, and optional DiskImageKit overlay layers on macOS 27.

05

Reliable networking

Simple NAT networking gives virtual machines shared Internet access without privileged networking entitlements.

06

Native integrations

Linux Rosetta sharing, Virtio devices, EFI Secure Boot, memory ballooning, and guest provisioning when supported.

Always current

Choose a release, not just “latest.”

macOS signed releases update dynamically and download from Apple. The Linux installer catalog updates independently through this site, so new supported images do not require a new EZVM build.

  1. 01
    macOS 12 through current releases

    Pick a signed IPSW from the refreshed catalog or let Apple resolve the newest version compatible with your Mac.

  2. 02
    Ubuntu, Debian, and Fedora ARM64

    Use curated native installers, a custom HTTPS URL, or any local ISO.

  3. 03
    Offline-friendly image store

    Downloaded images are kept once and shared by future VM creation workflows.

  4. 04
    Useful diagnostics

    Export version, host, and VM configuration details directly from Community & Feedback when asking for help.
